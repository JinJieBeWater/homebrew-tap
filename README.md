# JinJieBeWater Tap

## How do I install these formulae?

`brew install jinjiebewater/tap/<formula>`

Or `brew tap jinjiebewater/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "jinjiebewater/tap"
brew "<formula>"
```

## Qujing

```bash
brew install jinjiebewater/tap/qujing
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
